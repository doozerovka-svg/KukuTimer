# ADR-003: Движок точных таймеров и уведомлений

## Status
Accepted

## Date
2026-08-28

## Context
Ядро философии Kuku Timer — это точные временные интервалы. После 10-минутного ожидания ("варки риса"), у пользователя открывается 2-минутное окно ("окно возможностей"), чтобы зайти в приложение.
Критически важно, чтобы пользователь получил уведомление о начале этого 2-минутного окна **ровно** через 10 минут, даже если экран телефона выключен, а само устройство находится в режиме глубокого сна (Doze mode).

## Decision
Используется **`AlarmManager` с точными будильниками (`setExactAndAllowWhileIdle`)** в связке с `BroadcastReceiver` (`AlarmReceiver.kt`). 

## Alternatives Considered

### WorkManager
- **Плюсы**: Идеален для гарантированного выполнения фоновых задач, переживает перезагрузку устройства, отличный современный API.
- **Минусы**: Предназначен для *откладываемых* (deferrable) задач. ОС может задерживать выполнение WorkManager на минуты или даже десятки минут в целях экономии батареи (Doze mode, App Standby).
- **Отклонено**: Недопустимая погрешность. Если окно возможностей длится всего 2 минуты, задержка уведомления на 5 минут полностью ломает механику приложения.

### Handler / Coroutines delay() / CountDownTimer (в Foreground Service)
- **Плюсы**: Максимальная точность, простота реализации.
- **Минусы**: Требует постоянной работы процесса. Если система убьет процесс из-за нехватки памяти, таймер сбросится.
- **Отклонено**: Ненадежно для длительных интервалов при заблокированном экране.

## Consequences
- Начиная с Android 12 (API 31), для использования точных таймеров требуется декларировать и запрашивать разрешение `SCHEDULE_EXACT_ALARM`. Начиная с Android 13 (API 33) для показа уведомлений также требуется `POST_NOTIFICATIONS`.
- Требуется тщательная обработка жизненного цикла: при открытии "Окна возможностей" мы ставим точный будильник. Если окно пропущено, таймеры должны корректно инвалидироваться.
- Использование `setExactAndAllowWhileIdle` гарантирует вывод устройства из Doze mode ровно на момент отправки локального уведомления.
