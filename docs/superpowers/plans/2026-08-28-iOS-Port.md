# iOS Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a native iOS version of Kuku Timer using Swift, SwiftUI, and the Screen Time API.

**Architecture:** A monolithic Xcode project generated via XcodeGen (`project.yml`). It consists of a Main Application target and two App Extensions (Shield Configuration and Shield Action). State is shared via App Groups (`UserDefaults`). 

**Tech Stack:** Swift 5, SwiftUI, FamilyControls, ManagedSettings, XcodeGen.

## Global Constraints

- Minimum Deployment Target: iOS 16.0
- Bundle ID: `com.doozerovka.kukutimer`
- App Group ID: `group.com.doozerovka.kukutimer`
- Persistence: Shared `UserDefaults`
- Codebase Location: `ios/` directory within the current monorepo.
- Tooling: Use `XcodeGen` (project.yml) to generate the `.xcodeproj` since manual `.xcodeproj` modification by AI is error-prone.

### Task 2: Shared State & Core Logic

**Files:**
- Create: `ios/KukuTimer/Shared/TimerState.swift`

**Interfaces:**
- Produces: `enum TimerStatus`, `class TimerStateManager` for managing timestamps in `UserDefaults`.

- [ ] **Step 1: Write TimerStateManager**

Create `ios/KukuTimer/Shared/TimerState.swift`:
```swift
import Foundation

public enum TimerStatus: String {
    case idle
    case cooking
    case ready
}

public class TimerStateManager {
    public static let shared = TimerStateManager()
    private let defaults = UserDefaults(suiteName: "group.com.doozerovka.kukutimer")
    
    private let statusKey = "timerStatus"
    private let cookStartTimeKey = "cookStartTime"
    
    public var status: TimerStatus {
        get {
            guard let rawValue = defaults?.string(forKey: statusKey),
                  let state = TimerStatus(rawValue: rawValue) else { return .idle }
            
            // Check if cooking expired
            if state == .cooking, let startTime = cookStartTime, Date().timeIntervalSince(startTime) >= 600 {
                return .ready
            }
            return state
        }
        set {
            defaults?.set(newValue.rawValue, forKey: statusKey)
        }
    }
    
    public var cookStartTime: Date? {
        get { defaults?.object(forKey: cookStartTimeKey) as? Date }
        set { defaults?.set(newValue, forKey: cookStartTimeKey) }
    }
    
    public func startCooking() {
        cookStartTime = Date()
        status = .cooking
    }
    
    public func reset() {
        cookStartTime = nil
        status = .idle
    }
}
```

class ShieldConfigurationExtension: ShieldConfigurationDataSource {

                subtitle: ShieldConfiguration.VisualContent(text: "Take a breath. Do you really need to open this app right now?", color: .white),

### Task 5: Shield Action Extension

**Files:**
- Create: `ios/ShieldAction/ShieldActionExtension.swift`

**Interfaces:**
- Consumes: `TimerStateManager` from Task 2.
- Produces: `ShieldActionDelegate` that handles button taps and unshields apps.

- [ ] **Step 1: Implement Action Delegate**

Create `ios/ShieldAction/ShieldActionExtension.swift`:
```swift
import ManagedSettings
import UserNotifications

class ShieldActionExtension: ShieldActionDelegate {
    override func handle(action: ShieldAction, for application: ApplicationToken, completionHandler: @escaping (ShieldActionResponse) -> Void) {
        switch action {
        case .primaryButtonPressed:
            let status = TimerStateManager.shared.status
            
            if status == .idle {
                // Start 10 min timer
                TimerStateManager.shared.startCooking()
                scheduleNotification()
                completionHandler(.none) // Keep shield up
            } else if status == .ready {
                // Remove shield
                let store = ManagedSettingsStore()
                store.shield.applications?.remove(application)
                TimerStateManager.shared.reset()
                completionHandler(.defer)
            } else {
                completionHandler(.none)
            }
        case .secondaryButtonPressed:
            completionHandler(.defer)
        @unknown default:
            completionHandler(.defer)
        }
    }
    
    private func scheduleNotification() {
        let center = UNUserNotificationCenter.current()
        let content = UNMutableNotificationContent()
        content.title = "Rice is Ready!"
        content.body = "You have 2 minutes to open your app."
        content.sound = .default
        
        let trigger = UNTimeIntervalNotificationTrigger(timeInterval: 600, repeats: false)
        let request = UNNotificationRequest(identifier: UUID().uuidString, content: content, trigger: trigger)
        center.add(request)
    }
}
```
